# Collectly - AI-Powered Revenue Operations for Modern Finance

Collectly is a high-fidelity SaaS landing page designed for B2B billing automation. Built with a focus on premium aesthetics, cinematic animations, and pixel-perfect responsiveness, it showcases the power of AI in simplifying complex financial workflows.

## 🚀 Key Features

- **Premium UI/UX**: A modern, dark/light hybrid aesthetic with glassmorphism and subtle gradients.
- **Interactive Workflow Cards**: Animated cards illustrating the journey from document extraction to verified invoices.
- **AI-Powered Insights**: Real-time cash flow visualizations and automated reconciliation previews.
- **Cinematic Branding**: A giant, partially obscured "Collectly" wordmark section that creates a high-end atmospheric feel.
- **Responsive Navigation**: A floating, scroll-reactive navbar that adapts across all devices.
- **Sub-Footer Branding**: Custom floating bottom bar celebrating the global team: "Built with ❤️ in India for San Francisco".

## 🛠 Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Custom local font integration for consistent branding.
- **Visualization**: [Recharts](https://recharts.org/) for automated financial graphs.

## 📦 Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rajneeshverma1/Collectly.git
   cd Collectly/collectly-app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

## 📂 Project Structure

- `src/app`: Next.js App Router pages and global styles.
- `src/components`: Reusable UI components (Hero, Navbar, Features, etc.).
- `public/`: Assets including the premium dashboard background images and custom fonts.
